2. Buka folder project di VS Code
3. Klik kanan `index.html` → **Open with Live Server**
4. Website terbuka dengan auto-reload

### Opsi 3: Online Hosting
1. Upload ke **GitHub Pages**, **Netlify**, atau **Vercel**
2. Share link ke temanmu

## 🎨 CUSTOMIZE WEBSITE

### **Ganti Warna Tema:**
Buka `style.css` dan edit di bagian `:root`:
```css
:root {
    --color-primary: #ff1744;      /* Pink utama */
    --color-secondary: #f50057;    /* Pink sekunder */
    --color-accent: #ff4081;       /* Aksen */
    --color-gold: #ffd700;         /* Emas */
}
```

### **Ganti Pertanyaan Quiz:**
Buka `index.html` section 5, edit:
```html
<h3 class="question-text">Pertanyaan Anda?</h3>
```

### **Ganti Pesan:**
Edit semua text di `index.html` sesuai keinginan

### **Tambah Foto:**
Di section 2, copy paste `.gallery-item` dan ganti content

### **Ganti Musik:**
Buka `index.html`, ganti URL di:
```html
<audio id="bgMusic" loop>
    <source src="URL_MUSIK_ANDA.mp3">
</audio>
```

## 🐛 TROUBLESHOOTING

### **Musik tidak auto-play?**
✅ Browser modern block autoplay. Klik tombol musik manual.

### **Animasi lag?**
✅ Tutup tab lain, pastikan hardware acceleration aktif.

### **Layout berantakan di mobile?**
✅ Clear cache browser atau gunakan browser modern.

### **Amplop tidak bisa diklik?**
✅ Pastikan JavaScript enabled. Refresh page.

### **Fireworks tidak muncul?**
✅ Jawab quiz dengan benar atau tunggu di section 8.
